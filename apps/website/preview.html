🌐 Ntsamaela Website Preview

Choose one of these methods to preview the website:

Method 1: Open Directly in Browser

Simply double-click the index.html file in the apps\website folder.

Or right-click → Open with → Your browser

Method 2: Using Python (if installed)

Open PowerShell in the apps\website folder and run:

python -m http.server 8000

Then open: http://localhost:8000

Method 3: Using Node.js (if installed)

Open PowerShell in the apps\website folder and run:

npx http-server -p 8000

Then open: http://localhost:8000

Method 4: Using VS Code Live Server

If you have VS Code:

  1. Install "Live Server" extension
  2. Right-click on index.html
  3. Select "Open with Live Server"
